Аппаратная изоляция (Обход бот-систем)

Большие сервисы (Google, Outlook, Yandex) считывают ваш цифровой отпечаток (fingerprint). Если регистрировать аккаунты из обычного браузера или через стандартный режим инкогнито, антифлуд-системы моментально свяжут сессии между собой и заблокируют сеть.

Инструменты для изоляции сессий:

  • Антидетект-браузеры (Dolphin{anty}, AdsPower, Multilogin): Они подменяют на уровне исходного кода браузера параметры Canvas, WebGL, аудио-отпечатки, WebRTC и заголовки User-Agent. Каждая вкладка выглядит для целевого сервиса как новое физическое устройство.
  • Автоматизация через библиотеки (Playwright / Selenium + Stealth плагины): Используется для написания скриптов-регистраторов. Обязательно применение патчей, скрывающих переменную navigator.webdriver.

Глубокая настройка отпечатка:

В настройках профилей необходимо настраивать WebGL и Canvas (шумирование хэша картинок), AudioContext (уникализация аудио-паспорта), а также список системных шрифтов. Параметры экрана (Screen & Viewport) обязаны идеально соотноситься с размером окна браузера, а язык и часовой пояс — на 100% совпадать с геопозицией вашего прокси-сервера.

Сетевой контур (Прокси)

Тип и качество IP-адреса — главный фактор, определяющий, потребует ли сервис номер телефона при регистрации.

  • Запрещено использовать: Бесплатные прокси, пакетные серверные (Datacenter) IP. У них нулевой уровень доверия (Trust Score), они находятся в черных списках почтовых систем. При попытке зайти с такого IP вы получите мгновенное требование номера или бесконечную капчу.
  • Необходимо использовать:
    1. Мобильные прокси (с ротацией по ссылке/времени): Обладают максимальным доверием. На одном IP-адресе оператора связи могут сидеть тысячи реальных людей.
    2. Резидентные прокси (Residential): IP-адреса реальных домашних провайдеров. Оплата обычно идет за гигабайт трафика.

Важно: Контролируйте пассивный отпечаток ОС (p0f/MTU). Если ваш User-Agent заявляет Windows, а структура сетевых пакетов указывает на Linux-сервер — сессия мгновенно помечается как подозрительная. Утечки через WebRTC должны быть переведены в режим эмуляции локального IP, но не отключены полностью.

Регистрация с номером (SMS-активаторы)

Если сервис жестко требует привязку телефона, этот этап автоматизируется через API сервисов временных номеров. К проверенным шлюзам относятся SMS-Activate, 5Sim, Grizzly SMS и SmsMan.

При использовании SMS страна номера телефона обязана совпадать со страной прокси. Использование индонезийского номера на немецком IP-адресе ведет к моментальной блокировке.

meridian/sms_handler.py Python 3.x 
import requests
import time

class SMSActivateAPI:
    def __init__(self, api_key: str):
        self.url = "https://api.sms-activate.org/stubs/handler_api.php"
        self.key = api_key

    def get_number(self, service: str, country: int) -> tuple:
        params = {
            'api_key': self.key,
            'action': 'getNumber',
            'service': service,
            'country': country
        }
        response = requests.get(self.url, params=params).text
        if "ACCESS_NUMBER" in response:
            return response.split(":")[1], response.split(":")[2]
        return None, response

    def wait_for_code(self, activation_id: str, max_wait=120) -> str:
        params = {
            'api_key': self.key,
            'action': 'getStatus',
            'id': activation_id
        }
        start_time = time.time()
        while time.time() - start_time < max_wait:
            response = requests.get(self.url, params=params).text
            if "STATUS_OK" in response:
                return response.split(":")[1]
            time.sleep(5)
        return None

Регистрация без номера & Эмуляция поведения

Чтобы создать аккаунт без привязки телефона и избежать последующих блокировок, необходимо сымитировать поведение идеального живого пользователя:

  • Прогрев прокси: Перед переходом на страницу регистрации откройте 2-3 нейтральных сайта (новости, поисковики), чтобы набить файлы cookie в профиле браузера.
  • Использование "чистых" путей: На Яндексе при регистрации выбирайте опцию «У меня нет телефона» (через контрольный вопрос). В Outlook выбирайте способ авторизации через резервную почту.
  • Эмуляция ввода (Human-like ввод): Роботизированный ввод текста моментально фиксируется внутренними скриптами защиты. Символы должны вводиться с задержкой (от 50 до 150 мс между нажатиями) и эмуляцией движения мыши по кривым Безье.

Специфика целевых сервисов

Google Hard

Требует телефон почти всегда. Окно «Пропустить» появляется только при регистрации через эмуляцию мобильного устройства (User-Agent Android) на чистейших резидентных IP.

Outlook Medium

Лоялен при создании, жесткий на первой авторизации. Позволяет регистрироваться через резервную почту. Используйте свои копеечные домены с Catch-All вместо публичных TempMail.

Яндекс Easy

Имеет кнопку «У меня нет телефона». Требует контрольный вопрос. Ответ на вопрос должен быть уникальным для каждой сессии, чтобы алгоритмы не связали сетку аккаунтов.

Yahoo Hard

Самая агрессивная бот-система. Без номера телефона регистрация невозможна. Принимает номера ограниченного пула стран (лучше всего использовать США/Великобританию).

Rambler Easy

Номер не требует, запрашивает простую капчу. Низкий начальный траст: авторизация через IMAP без предварительного прогрева в веб-интерфейсе ведет к мгновенному блоку.

Миф о 100% обходе без номера

Создать аккаунт Google (Gmail) абсолютно без номера телефона в промышленных масштабах сейчас невозможно. Если антифлуд-система видит массовую активность, она переводит форму в режим обязательной SMS-верификации. Окно пропуска доступно только для единичных сессий с идеальной репутацией.

Теневой бан (Скрытые блоки)

Если вы смогли зарегистрировать почту без номера, используя среднее качество прокси, аккаунт может уйти в скрытый блок. Вы сможете войти в панель, но при попытке отправить первое письмо система выдаст ошибку или заблокирует аккаунт до тех пор, пока вы не привяжете реальный номер телефона.

Капча-ловушка

Если при регистрации вы видите бесконечную или нечитаемую капчу (Arkose Labs, ReCaptcha v3) — это означает, что ваш IP-адрес или цифровой отпечаток уже скомпрометированы. Дальнейшая работа в этой сессии бессмысленна, аккаунт будет заблокирован в течение суток. Сессию нужно немедленно закрывать и менять IP.

Лимиты мобильных прокси

При использовании мобильных прокси меняйте IP-адрес по ссылке (ротация) строго после каждой успешной регистрации или после двух неудачных попыток подряд. Повторная регистрация на том же IP без смены гарантирует принудительный запрос номера.
